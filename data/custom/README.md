# Власні фото для донавчання

Сюди кладіть фото лотків підприємства (JPEG). У git і в деплой вони **не потрапляють** (див. `.gitignore`) — у репозиторії лише цей файл.

Найпростіше джерело таких фото — експорт із застосунку: **Історія → Експортувати все у файл (ZIP)**. У ньому є `photos/<id>.jpg`
і `export.json` з оцінками сортувальника для тих самих фото.

## Як додати фото в навчання

1. Скопіюйте фото сюди. Якщо ягода не ожина, покладіть фото в підпапку з назвою профілю: `raspberry/`, `blueberry/`, `strawberry/`.
2. Зробіть автопідказку розмітки кольоровим методом:
   ```
   node tools/autolabel.js
   ```
   Поруч із кожним фото з'являться `<ім'я>.label.png` (розмітка) і `<ім'я>.preview.png` (фото з кольоровим шаром).
3. Перегляньте `*.preview.png`. Якщо підказка погана (пліснява на білому, не помічена пліснява) — **видаліть `.label.png`**
   цього фото, і воно в навчання не піде. Розмітку можна й виправити в будь-якому редакторі, що зберігає PNG у відтінках сірого
   (значення пікселя = номер класу: 0 фон, 1 якісна, 2 недостигла, 3 пошкоджена, 4 пліснява, 5 домішки).
4. Перебудуйте дані й донавчіть модель:
   ```
   .venv\Scripts\python.exe training\prepare.py
   .venv\Scripts\python.exe training\train.py --name v2
   ```

Автопідказка повторює помилки кольорового методу, тож сама по собі модель від неї не покращиться. Користь дають фото,
де підказку виправила людина, і пари «програма — сортувальник» з експорту (див. EVALUATION.md, розділ «Що далі»).
